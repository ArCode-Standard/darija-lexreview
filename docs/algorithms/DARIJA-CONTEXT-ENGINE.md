# محرك فهم سياق الدارجة المغربية

## النطاق

هذه طبقة تحليل متعددة الإشارات فوق التطبيع ومعجم سلامة المحتوى. هدفها التمييز الأولي بين:
- الإساءة الموجهة المحتملة.
- المزاح أو الضحك بوصفه قرينة، لا إعفاءً.
- الاقتباس أو نقل كلام شخص آخر.
- السؤال اللغوي أو التعريف أو الشرح.
- صياغة تهديد محتملة.
- الحالات غير الواضحة أو المتضاربة.

## API

`analyzeDarijaContext({ text, matchedCategories })` يعيد:
- `primary`: التصنيف الأرجح وفق قواعد حتمية.
- `labels`: جميع التصنيفات التي تدعمها الإشارات؛ يسمح بتعددها.
- `confidence`: منخفض/متوسط/مرتفع، وهو مستوى إرشادي لا احتمال إحصائي معاير.
- `requiresHumanReview`: هل تتطلب الحالة مراجعة بشرية.
- `cueCodes`: رموز الإشارات التي أدت إلى التقييم.
- `trustedForEnforcement: false`: ثابت يوضح أن النص وحده لا يمنح صلاحية إنفاذ.

## قواعد تفسير التعارض

1. وجود ضحك مع إهانة ومخاطب مباشر يصنف الحالة مختلطة وملتبسة؛ لا يفترض أن الإهانة مزاح بريء.
2. السؤال عن معنى لفظ مسيء يصنف كذكر لغوي، مع الاحتفاظ بإشارة المعجم الأصلية.
3. نقل تهديد في بلاغ يظل تهديداً مقتبساً يحتاج مراجعة؛ الاقتباس لا يمحو الخطر.
4. وجود لفظ مسيء دون مخاطب موثوق لا يثبت الاستهداف.
5. صياغة تهديد محتملة من النص ترفع الحالة للمراجعة ولا تنفذ حظراً أو تصعيداً آلياً وحدها. تُفحص بعض صيغ النفي الصريحة لتقليل تصنيف النفي على أنه تهديد، لكن تغطية النفي ما زالت محدودة.
6. لا يحق للعميل إرسال `matchedCategories` أو `TrustedContentContext` بوصفها حقائق موثوقة؛ يجب اشتقاقها داخل الخادم من المحرك ومسار الطلب.

## حدود النسخة

- القواعد الحالية تغطي عدداً محدوداً من الصيغ الشائعة، ولا تمثل جميع المناطق أو التهجئات المغربية.
- لا يوجد نموذج ML مدرب أو فهم دلالي عميق أو تحليل سخرية موثوق.
- مستويات الثقة قواعدية وغير معايرة.
- قد تخطئ الإشارات عند اللهجات المختلطة أو التلميح أو الاستعارة أو غياب السياق السابق.
- يجب توسيع benchmark بأمثلة مرخصة ومراجعة مزدوجة، ثم قياس الأداء حسب التصنيف والنص والسياق قبل اعتماد أي نموذج.

## اختبارات القبول

- سؤال لغوي يتضمن لفظاً فاحشاً.
- إهانة مع ضمير مخاطب.
- إهانة مع ضحك وإظهار التعارض.
- ضحك بلا إساءة.
- تهديد مقتبس في بلاغ.
- جملة محايدة بلا قرائن.
- التأكد أن `trustedForEnforcement` يبقى false في كل الحالات.
