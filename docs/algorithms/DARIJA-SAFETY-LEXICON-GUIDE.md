# معيار بناء معجم سلامة الدارجة المغربية

## الهدف

المعجم طبقة إشارات لغوية أولية. لا يقرر وحده أن الكاتب يسيء إلى شخص، ولا يثبت النية أو الهدف. وظيفة المعجم هي اقتراح المطابقة وإحالة الحالات الملتبسة إلى تحليل السياق أو المراجعة البشرية.

## سجل كل مدخل

قبل اعتماد أي لفظ جديد، يجب أن يتضمن سجل التحرير:

| الحقل | المطلوب |
|---|---|
| `id` | معرّف ثابت لا يعاد استخدامه |
| `phrase` | الصيغة كما تظهر في النص |
| `variants` | تهجئات عربية ولاتينية وArabizi وصيغ الفصل/الدمج |
| `category` | profanity أو personal_abuse أو hate_speech أو threat |
| `severity` | شدة لغوية من 1 إلى 5، وليست احتمال الإساءة |
| `sense` | شرح المعنى المقصود بالدارجة |
| `region` | المنطقة أو التنبيه إلى أن الاستعمال غير محصور جغرافياً |
| `examples` | مثال استعمال طبيعي ومثال محايد مضاد عند وجود التباس |
| `false_positive_risk` | منخفض أو متوسط أو مرتفع مع سبب |
| `source` | مصدر لغوي أو مثال مرخص أو تصحيح محرر |
| `review_status` | candidate أو reviewed أو rejected أو retired |
| `reviewers` | مراجعتان مستقلتان عند إدخال المثال إلى بيانات سلامة المحتوى |

هذه حقول سجل التحرير المرجعي؛ لا يعني وجودها في هذا الدليل أنها كلها مطبقة بعد في واجهة TypeScript الحالية.

## قواعد القبول

1. لا تضف كلمة لمجرد تشابهها الكتابي مع كلمة مسيئة.
2. لا تعتمد لفظاً متعدد المعاني دون شرح المعنى والسياق المقصود.
3. افصل اللفظ الفاحش عن الإهانة الشخصية وعن خطاب الكراهية والتهديد.
4. أضف صيغ العربية وArabizi كل واحدة كصيغة قابلة للاختبار.
5. لا تحول شدة اللفظ إلى حظر تلقائي؛ الإهانة الشخصية تحتاج سياق استهداف موثوقاً من الخادم.
6. احتفظ بأمثلة محايدة وتعليمية واستخدامات اقتباس لقياس الإنذارات الكاذبة.
7. لا تستخدم الرسائل الخاصة أو بيانات المستخدمين للتدريب دون موافقة صريحة وترخيص صالح.
8. لا تصدر مجموعة تدريب إلا بعد مراجعتين مستقلتين وتوثيق المصدر والترخيص.
9. لا تعتبر التصحيح الفردي حقيقة لغوية نهائية؛ اجمع الشواهد واختبر الاختلافات الجهوية.
10. عند الشك، ارفع الحالة للمراجعة بدلاً من الحظر.

## اختبارات مطلوبة لكل دفعة

- مطابقة الصيغة العربية الأصلية.
- مطابقة صيغ Arabizi المعتمدة.
- مطابقة التشكيل والتطويل واختلاف الهمزات.
- مطابقة فصل الحروف بالمسافات أو علامات ترقيم محدودة.
- عدم المطابقة داخل كلمة أطول غير مرتبطة.
- عدم الحظر في تعريف معجمي أو اقتباس بلاغ موثوق.
- عدم حظر إهانة محتملة دون سياق استهداف موثوق.
- حظر/تصعيد الحالة فقط عند توفر شروط السياسة والسياق الموثوق.
- قياس precision وrecall وFPR وFNR لكل فئة على مجموعة اختبار لم تدخل في التحرير.

## حدود النسخة الحالية

النسخة الحالية معجم تأسيسي صغير وقواعد حتمية. لم تُدرّب نموذجاً لغوياً، ولا تمثل جميع مناطق المغرب أو جميع تهجئات المستخدمين. يجب توسيعها عبر مجموعة بيانات مغربية مرخصة ومراجعة من متحدثين أصليين، ثم مقارنة الأداء على أمثلة لم تُستخدم في التطوير.
