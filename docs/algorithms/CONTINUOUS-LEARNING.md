# التعلم المستمر وحوكمة البيانات والتدريب

## المبدأ

تتعلم المنظومة من الملاحظات وقرارات المحررين ونتائج الاختبارات، لكن لا تتعلم مباشرة من كل رسالة أو اقتراح. الهدف تحسين المحركات دون السماح بتسميم البيانات أو تحويل تصويت المستخدمين إلى حقيقة لغوية أو قرار سلامة.

## مصادر الإشارات

- اقتراحات المستخدمين للكلمات والمرادفات والتهجئات والتصحيحات.
- تصحيحات المحررين المعتمدة على المدخلات والشواهد.
- قرارات الإشراف بشأن الإساءة والإنذارات الخاطئة والحالات الفائتة.
- اختبارات الجودة والتقييمات المرجعية.
- بيانات عامة مرخصة أو مجموعات جُمعت بموافقة واضحة وحقوق استخدام موثقة.

لا تُعتبر الرسائل الخاصة مصدراً تدريبياً افتراضياً. لا تدخل بيانات شخصية أو حساسة أو نصوص خاصة في التدريب دون أساس قانوني وسياسة معلنة وموافقة مناسبة ومراجعة خصوصية وأمن.

## مستويات التعلم

### 1. التعلم المعجمي (Lexical learning)
- اقتراح مفردة أو صيغة أو مرادف أو تصحيح.
- تخزين الاقتراح في حالة pending مع مصدره وبيانات الإثبات.
- التحقق من التكرار والتعارض وجودة الشاهد وحقوق المصدر.
- اعتماد محرر مخول أو مراجعين حسب مستوى التأثير.
- لا تنتقل القيمة المعتمدة تلقائياً إلى قاموس الإنتاج دون مسار إصدار ومراجعة.

### 2. التعلم الإحصائي (Statistical calibration)
- تحليل قرارات المحررين ومعدلات الإنذار الخاطئ والحالات الفائتة.
- اقتراح تعديل الأوزان والعتبات.
- مقارنة الأثر على مجموعة التقييم الثابتة ومجموعات الشرائح المختلفة.
- لا يسمح بتعديل عتبات السلامة عبر تصويت المستخدمين.

### 3. إعادة التدريب (Model retraining)
- لا يبدأ إلا عند توفر بيانات كافية، نظيفة، مرخصة، معتمدة وممثلة للفئات والسياقات.
- فصل بيانات التدريب والتحقق والاختبار، مع منع تسرب الأمثلة بين المجموعات.
- حفظ وصف البيانات وإصدارها وبصمتها ومصدرها وحقوق استخدامها.
- تسجيل إعدادات التدريب وبصمة الكود وإصدار النموذج.
- لا يُنشر النموذج لمجرد انتهاء التدريب؛ يجب أن يجتاز بوابات التقييم.

## دورة حياة الملاحظة

1. **Capture**: جمع الإشارة مع الحد الأدنى من البيانات.
2. **Deduplicate**: إزالة التكرار وكشف الحملات المنسقة.
3. **Validate**: فحص الصيغة والمصدر والحقوق والسياق.
4. **Review**: اعتماد أو رفض بشري مع سبب.
5. **Curate**: إدخال الأمثلة المقبولة في مجموعة مرجعية ذات إصدار.
6. **Train / Calibrate**: تحديث القواعد أو الأوزان أو تدريب نموذج وفق الحاجة.
7. **Evaluate**: قياس الجودة ومقارنة الإصدار السابق.
8. **Release**: إصدار تدريجي بعد الموافقات.
9. **Monitor**: مراقبة الانحراف والأخطاء والأداء.
10. **Rollback**: العودة إلى إصدار سابق عند تدهور المؤشرات.

## مقاومة Data Poisoning

- اقتراح المستخدم غير موثوق مهما بلغ عدد مرات تكراره.
- الاقتراحات المستقلة المتكررة ترفع أولوية المراجعة فقط ولا تعني الاعتماد.
- اعتماد المحرر موثق بحسابه وصلاحيته ووقت القرار.
- التغييرات عالية التأثير أو المتعلقة بالسلامة تتطلب مراجعة مزدوجة أو إدارية.
- كشف الأنماط المنسقة ومعدلات الإرسال غير الطبيعية.
- لا يمكن للمستخدمين تغيير سياسات السلامة أو قوائم الحماية بالتصويت.
- افصل صلاحية اقتراح البيانات عن صلاحية اعتمادها أو نشرها.

## مجموعة التقييم ومقاييس الجودة

لكل مهمة، استخدم بيانات موسومة بشرياً وممثلة للهجات والكتابات والسياقات. أبلغ على الأقل عن:
- Precision وRecall وF1 لكل فئة.
- False Positive Rate وFalse Negative Rate.
- Confusion matrix.
- معايرة الثقة عند استخدام درجات احتمالية.
- النتائج حسب نوع السطح واللهجة ونمط الكتابة.
- زمن الاستجابة واستهلاك الموارد.
- حجم مجموعة الاختبار وتاريخها ومصدرها وحدود تمثيلها.

لا تعرض دقة إجمالية تخفي فشل فئة عالية الخطورة. حدد حدود القبول قبل التدريب، ولا تستخدم أرقام مجموعة صغيرة أو مؤقتة كادعاء دقة واقعية.

## سجل مصدر البيانات (Data provenance)

لكل مثال معتمد، احتفظ بما يلزم من:
- معرف داخلي غير كاشف للهوية.
- نوع المصدر ورابطه أو مرجعه.
- الترخيص/الإذن وأساس الاستخدام.
- اللغة واللهجة ونظام الكتابة والسياق.
- وسم المثال وسبب الوسم.
- هوية المراجع بصيغة داخلية محكومة.
- تاريخ الاعتماد وإصدار مجموعة البيانات.

لا تخزن بيانات هوية المستخدم أو نصوصاً خاصة أكثر مما تتطلبه سياسة الاحتفاظ.

## سجل النماذج والإصدارات

كل إصدار يتضمن:
- model/rules version.
- dataset version and fingerprint.
- code commit.
- training configuration.
- evaluation report.
- reviewers and approval.
- release channel and rollback target.

الإصدارات غير قابلة للاستبدال الصامت. كل تحديث إصدار جديد موثق.

## شروط الإطلاق

- لا أخطاء أمنية أو تسرب بيانات.
- لا تراجع غير مقبول في أي فئة أساسية.
- اجتياز اختبارات التحايل والسياقات المشروعة.
- مراجعة بشرية للتغييرات المؤثرة.
- خطة مراقبة وتراجع.
- اعتماد واضح قبل الإنتاج.

## الوضع الحالي

لم يُنفذ خط تدريب فعلي ولم يُنتج نموذج مدرب بموجب هذه الوثيقة. أي benchmark أو خوارزمية حتمية موجودة لا تعني وجود نموذج تعلم آلي مدرب. التدريب الفعلي مرحلة لاحقة تعتمد على مجموعة بيانات مرجعية صالحة وبنية تقييم قابلة لإعادة الإنتاج.
