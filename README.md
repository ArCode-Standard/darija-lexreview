# ArCode Darija LexReview

منصة مراجعة لغوية تعاونية قائمة على الأدلة لتحسين بيانات الدارجة المغربية، من تطوير **ArCode Standard**.

**الحالة:** أساس MVP قابل للتشغيل محلياً. ربط Supabase واستيراد المعجم والنشر السحابي خطوات إعداد مطلوبة قبل استقبال مراجعات حقيقية.

## الهدف

تمكين المراجعين من فحص المفردات وتصحيحها من المتصفح دون تنزيل المستودع أو استخدام Git. يمكن للمراجع اقتراح تصحيح، وإضافة أمثلة وشواهد وملاحظات. تبقى كل المساهمات **مقترحات غير معتمدة** حتى يراجعها محرر مخوّل.

## المعمارية

- React + TypeScript + Vite للواجهة.
- Supabase للمصادقة وتخزين المقترحات وسير المراجعة.
- [المعجم الرسمي](https://github.com/ArCode-Standard/moroccan-darija-dataset) مصدر الحقيقة للبيانات المنشورة.
- GitHub Pull Request لنقل التعديلات المعتمدة إلى مستودع البيانات (تكامل لاحق).
- Cloudflare Pages هدف النشر المقترح.

قاعدة بيانات التطبيق ليست نسخة رسمية ثانية من المعجم، ولا يؤدي إرسال المقترح إلى تعديل البيانات المنشورة مباشرة.

## التشغيل المحلي

```bash
npm install
cp .env.example .env
npm run dev
```

أضف بيانات مشروع Supabase إلى ملف `.env`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY
```

نفّذ الملفات بالترتيب التالي في SQL Editor داخل Supabase:

1. للمشروع الجديد فقط: [supabase/schema.sql](supabase/schema.sql) لإنشاء الجداول وسياسات RLS الأساسية.
2. طبّق ملفات [supabase/migrations](supabase/migrations) بالترتيب التصاعدي لأسمائها، بما فيها `20261101130441_security_governance_hardening.sql` و`20261101130559_audit_actor_index.sql`.
3. للمشروع القائم الذي سبق تطبيق المخطط الأساسي عليه: لا تُعد تشغيل المخطط الأساسي؛ طبّق ملفات الترحيل الجديدة غير المسجلة فقط وبالترتيب.

لا تفتح استقبال المساهمات العامة قبل تطبيق الترحيلات والتحقق من الصلاحيات بحسابات اختبار منفصلة.

## سير المراجعة

1. اختيار مدخل معجمي.
2. فحص الكتابة العربية وArabizi والمعنى والترجمة والسياق.
3. البحث عن شواهد مستقلة وإرفاق روابطها.
4. إرسال اقتراح يظل بحالة pending.
5. محرر مخوّل يقبل أو يرفض المقترح.
6. تُنقل التغييرات المقبولة لاحقاً عبر Pull Request إلى مستودع البيانات.

**تنبيه لغوي:** نتيجة محرك البحث ليست دليلاً كافياً على صحة الكلمة أو معناها. ينبغي تقييم سياق الشاهد ومصدره واستعماله الفعلي في الدارجة المغربية.

## نطاق النسخة الحالية

- واجهة عربية RTL متجاوبة.
- قائمة مراجعة مع بيانات توضيحية عند عدم تهيئة المصدر.
- نموذج اقتراح يتضمن الحقول اللغوية والأدلة.
- تكامل Supabase اختياري عبر متغيرات البيئة.
- ملف SQL أساسي، تليه ترقية أمنية إلزامية لتثبيت قرارات المراجعة وتسجيلها.
- المحرر لا يستطيع مراجعة مقترحه الشخصي، ولا تعديل محتوى المقترح بعد إرساله.
- سجل القرارات مستقل ولا يملك مستخدمو التطبيق صلاحية تعديله أو حذفه.
- التصدير لا يفترض ملكية الحقوق أو أذونات إعادة الاستخدام؛ القيم غير المثبتة تبقى `unknown`، وتُطلب مراجعة بشرية قبل الدمج.
- المقترحات المتعارضة على المدخل نفسه تُوقف من التصدير حتى تسويتها.

استيراد المعجم الفعلي، صلاحيات المحررين، مراجعة الأدلة، وربط GitHub الآلي تتطلب إعداداً واختبارات قبل الإطلاق العام.
