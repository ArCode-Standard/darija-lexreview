# خوارزميات الدارجة وسلامة المحتوى والتعلم المستمر

هذه الوثائق هي نقطة الدخول الرسمية لتطوير محركات التحليل اللغوي وحماية المحتوى والتعلم المحكوم داخل منصة Darija LexReview.

## النطاق

1. **Darija Engine**: تطبيع النصوص، تحليل العربية وArabizi، اكتشاف اللهجات، المرادفات والاشتقاق، التشابه، وتصحيح الكتابة مع إبقاء الشكل الأصلي.
2. **Content Safety Engine**: رصد الإساءة الشخصية، الألفاظ النابية في سياقها، خطاب الكراهية، التهديد، التحايل الإملائي، الرسائل المزعجة والتكرار.
3. **Unified Content Gateway**: بوابة خادمية موحدة تفحص كل محتوى ينشئه المستخدم أو يعدله قبل اعتماده أو تخزينه في المسارات المحمية.
4. **Continuous Learning**: جمع الملاحظات، التحقق منها، بناء مجموعات بيانات مرجعية، التقييم، التدريب الدوري عند توفر بيانات كافية، وإدارة إصدارات النماذج والقواعد.
5. **Governance & Observability**: المراجعة البشرية، سجل القرارات، قياس الأخطاء والانحراف، التراجع عن الإصدارات، ومراقبة الأداء.

## مبادئ غير قابلة للتفاوض

- التنفيذ الأمني الحاسم يكون على الخادم، لا في واجهة React وحدها.
- لا يُقبل أي محتوى محمي عبر مسار كتابة يتجاوز بوابة الفحص.
- لا يعني ظهور لفظ نابي تلقائياً أن المحتوى إساءة؛ السياق التعليمي واللغوي والتوثيقي والاقتباس لأغراض البلاغات يجب أن يعالج بصورة مختلفة.
- اقتراحات المستخدمين إشارات غير موثوقة وليست حقائق لغوية أو قرارات سلامة.
- لا يحدث تدريب مباشر من الرسائل أو الاقتراحات الخام. الاعتماد البشري ومراجعة الجودة يسبقان إدخال الأمثلة إلى مجموعة التدريب.
- لا تستخدم الرسائل الخاصة أو البيانات الشخصية في التدريب افتراضياً. أي تغيير يتطلب أساساً قانونياً وسياسة خصوصية وموافقة مناسبة ومراجعة أمنية.
- لا يُنشر نموذج أو قاموس أو عتبة جديدة قبل اجتياز مجموعة تقييم ثابتة ومراجعة الإصدار.
- لا تتخذ الخوارزميات قرارات تحريرية لغوية نهائية ولا تستبدل صلاحيات المحررين.

## الحالة الحالية

هذه الوثائق تحدد التصميم وخطة العمل. لا تعني أن محرك سلامة المحتوى أو بوابة الفحص أو خط التدريب قد نُفذت أو دُربت أو رُبطت بالإنتاج. كل مرحلة ستُنفذ في تغييرات مستقلة قابلة للاختبار والمراجعة.

توجد طلبات دمج سابقة لمحرك الدارجة (#20 و#21 و#23) ومجموعة benchmark (#24). هذه الطلبات متداخلة وبعضها يعتمد على فروع أخرى؛ يجب مراجعتها وتوحيد ما يستحق إعادة الاستخدام قبل الدمج. لا تعتبر هذه الوثائق موافقة على دمج أي منها.
