REPORTING & SECURITY

الإبلاغ عن المحتوى والثغرات

اختر القناة المناسبة، ولا تضع بيانات شخصية أو أسرار وصول في بلاغ عام.

هذه قناة إجرائية أولية عبر GitHub. لا توجد حالياً خدمة دعم مستقلة أو اتفاقية زمن استجابة مضمونة.

الإبلاغ عن محتوى أو مساهمة

للإبلاغ عن محتوى مسيء أو مضلل أو منتهك لحقوق النشر أو يتضمن بيانات شخصية، أنشئ بلاغاً في متعقب المشروع مع وصف مختصر ورابط السجل أو الصفحة. لا تنشر بيانات شخصية حساسة أو مستندات خاصة أو معلومات اتصال لأشخاص آخرين.

فتح بلاغ محتوى على GitHub

إذا كان البلاغ يتطلب مشاركة معلومات شخصية أو سرية، لا تستخدم issue عاماً؛ لا توجد بعد قناة خاصة معتمدة لهذا النوع من الطلبات.

الإبلاغ عن ثغرة أمنية

أرسل تقريراً خاصاً عبر GitHub Security Advisories. يرجى تضمين وصف الأثر، والخطوات اللازمة لإعادة الإنتاج، والإصدارات أو المسارات المتأثرة، وأي دليل غير حساس. لا تختبر حسابات أشخاص آخرين، ولا تستخرج بيانات، ولا تنفذ تغييرات أو تعطيل للخدمة.

إرسال تقرير أمني خاص

يرجى منح الفريق وقتاً معقولاً للتحقق والمعالجة قبل الإفصاح العام. لا يوجد حالياً برنامج مكافآت ثغرات أو تعهد بمدة استجابة محددة.

طلبات الترخيص التجاري

للاستفسار عن ترخيص تجاري للبيانات، استخدم متعقب المشروع مع عنوان «استفسار ترخيص تجاري». لا ترسل معلومات سرية؛ فتح الاستفسار لا يعني منح الترخيص.
